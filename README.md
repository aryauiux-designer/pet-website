# BARKFY website

A responsive HTML, CSS and vanilla JavaScript front-end based on the two supplied BARKFY screenshots.

## Run it
1. Extract `barkfy-website.zip`.
2. Open `index.html` in a browser, or use VS Code's Live Server extension.
3. Keep the `assets` folder beside `index.html`.

## Included
- Splash screen using the supplied splash screenshot as the exact hero artwork.
- Timed upward splash transition and skip-intro control.
- Homepage sections in the order shown in the reference.
- Animated circular mascot ribbon.
- Responsive navigation, hover states and product cards.
- Sign-in modal triggered by sign-up, add-to-cart, cart and grooming booking actions.
- Contact and newsletter demo forms.

## Important notes
- The supplied homepage screenshot is a tall, low-resolution reference. The dog mascot and section reference crops are taken from that screenshot. Replace these crops with your original high-resolution exported Figma images for production-quality visuals.
- The product and grooming cards are front-end placeholders styled to match your layout. Replace the placeholder images and sample product details with your final assets/content.
- Sign-in, cart checkout, contact form delivery and newsletter subscription are front-end demonstrations only. They need a backend/authentication or form service to store real data and process orders.
- Fonts load from Google Fonts, so an internet connection is needed for Fraunces and Outfit.
- Brand colors are defined as CSS variables at the top of `styles.css`.
