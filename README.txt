BARKFY — DESKTOP HERO ONLY

This is only the first desktop screen. No dog image, product image, icon image, or other image asset is included.

FILES
- index.html
- style.css
- script.js

RUN
Open this folder in VS Code and run index.html with Live Server.

DOG IMAGE
The circle is intentionally empty. Add your own dog image inside the element with id="dogImagePlaceholder":
  <img class="mascot-photo" src="your-dog-image.png" alt="BARKFY dog mascot">

The current pointer effect nudges the added image toward the cursor. To make only the pupils track the cursor accurately, the dog's actual eye positions need to be calibrated after you add your image.

ANIMATIONS
- Curved BARKFY text rotates around the circular lavender ring.
- Bottom category ribbon scrolls continuously.
- Mascot image placeholder follows pointer movement when your image is added.
